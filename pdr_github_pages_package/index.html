1. V4 Parametric Sweep Findings Report

Full Technical Report · 20 Embedded Plots

Complete analysis of roughly 833,000 simulated half-duplex link configurations evaluating LED wavelengths (405–659 nm), photodiodes, optical filters, lenses, water clarity, ambient lighting, and receiver front-end topologies.

  • Explains the four noise/interference regimes (transmitter noise, receiver noise, shot noise, and lamp hum).
  • Documents both the Hamamatsu S1337-1010BR royal-blue path and the MTD5052W green-LED + condenser-lens path (47.8 dB on-axis at 15 ft).
  • Includes angular misalignment, ambient flicker, and water-clarity sensitivity plots.
